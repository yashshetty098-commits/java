# Java — Practice & Engineering Assessments

My Java coursework and practice repository from my B.Tech in Computer Science (AI & ML) — small, focused programs that build up the fundamentals one topic at a time.

## What's covered

| Folder / files | Topics |
|---|---|
| `01_Numbers_Conditions_Loops/` | Number problems, conditionals and loop control |
| `02_Strings/` | String handling and manipulation |
| `03_Basic_Arrays/` | Array basics — traversal, searching, simple operations |
| `04_Loops_and_Arrays/` | Combining loops with arrays |
| `05_2D_Arrays/` | Two-dimensional arrays and matrix-style problems |
| Root files | Standalone exercises — `Addition`, `AreaRectangle`, `EvenOdd`, `Factorial`, `LargestNumber`, `MultiplicationTable`, `SimpleInterest`, `SquareNumber`, plus small OOP exercises like `EmployeeDetails`, `StudentDetails` and multiple-object examples |

## Why this repo exists

- A running record of my Java learning during engineering — assessments and practice, kept in the open.
- Everything here compiles as plain Java with no frameworks or build tools: just `javac` and `java`.

## Running any program

```powershell
javac Factorial.java
java Factorial
```
